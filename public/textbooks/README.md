# Учебники Spotlight

Сюда кладутся PDF-файлы официальных учебников и тетрадей. Файлы **не** коммитятся
в git — они защищены авторским правом (Express Publishing / «Просвещение»). Каждый
учитель/школа кладёт свою легально приобретённую копию на свою машину.

## Структура

```
public/textbooks/
├── grade-2/
│   ├── spotlight-2-student-book-part-1.pdf
│   ├── spotlight-2-workbook.pdf
│   └── spotlight-2-teacher-book.pdf
├── grade-3/...
└── ...
```

Если PDF лежит по нужному имени, в учительском кабинете в плане урока появится
кнопка «Открыть учебник стр. 24» — она просто откроет PDF в новой вкладке с
прыжком на нужную страницу через `#page=24`.

## Где взять PDF

- Просвещение: https://prosv.ru/ — страница серии «Английский в фокусе»
- В личном кабинете учителя на сайте издательства (если приобретено через школу)
- Образовательные комплекты ФГОС (для государственных школ)

## Имена файлов (важно!)

Сервер ожидает строго эти имена:

| Класс | Файл                                    | Описание                  |
|-------|-----------------------------------------|---------------------------|
| 2     | `spotlight-2-student-book-part-1.pdf`   | Учебник, часть 1          |
| 2     | `spotlight-2-student-book-part-2.pdf`   | Учебник, часть 2 (опц.)   |
| 2     | `spotlight-2-workbook.pdf`              | Рабочая тетрадь           |
| 2     | `spotlight-2-teacher-book.pdf`          | Книга для учителя (опц.)  |

Если файла нет — соответствующая кнопка в UI просто не отобразится.
