## Системные требования

- **OS**: macOS / Linux / Windows (WSL рекомендован).
- **Node.js**: `20.x` LTS или новее (`node -v` должен показать `v20.…` или выше).
- **npm**: 10+ (идёт вместе с Node 20). `pnpm`/`yarn` тоже подойдут, но команды ниже — для `npm`.
- **Браузер**: последний Chrome / Edge / Firefox / Safari. PWA-фичи (установка приложения, офлайн-словарь) лучше всего видно в Chromium-семействе.
- **Свободного места**: ~600 МБ под `node_modules` + ~50 МБ под локальную SQLite-базу.
- **Сеть**: для AI/TTS-запросов нужен исходящий HTTPS на `api.groq.com`, `tts.api.cloud.yandex.net` и т.п. (см. [Опциональные интеграции](#опциональные-интеграции-по-очереди)). Без интернета приложение всё равно запустится — просто отключит соответствующие функции и упадёт на Web Speech.

## Минимальный запуск за 60 секунд

```bash
git clone https://github.com/kheymer17reg/English-Spotlight.git
cd English-Spotlight
npm install
cp .env.example .env.local         # ничего не редактируй для первого старта
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000). Если 3000 занят — Next автоматически займёт `:3001`.

**На пустой `.env.local` работает почти всё:**

- регистрация ученика/учителя/родителя по email + паролю,
- журнал, оценки, расписание, словарь, чтение,
- лента класса, парный роль-плей (без Lumos-коррекции — нужен ключ AI),
- доска (рисование, фигуры, заметки, экспорт в PNG),
- PWA-установка и офлайн-словарь.

**Не будет работать без ключей:**

- AI-помощник Lumos и автогенерация уроков/упражнений (нужен `GROQ_API_KEY` или альтернативный провайдер),
- TTS «как настоящий учитель» (нужен `YANDEX_SPEECHKIT_API_KEY` для русского, `GROQ_API_KEY` для Orpheus / английского). Без них озвучка автоматически переключается на Web Speech (синтез браузера).
- Google-логин (нужны `GOOGLE_CLIENT_ID` + `GOOGLE_CLIENT_SECRET`).

## Переменные окружения (.env.local)

Создаётся локально, в репозиторий **не коммитится** (`.env.local` уже в `.gitignore`).

```bash
# === База: NextAuth ===
NEXTAUTH_URL=http://localhost:3000
# Сгенерируй один раз и сохрани:
#   openssl rand -base64 32
NEXTAUTH_SECRET=<любая_длинная_строка_не_короче_32_символов>

# === AI-провайдер для Lumos / генерации уроков (опционально) ===
# Можно указать несколько ключей сразу — приложение возьмёт первый доступный.
# Чтобы зафиксировать конкретного — выстави LLM_PROVIDER.
# LLM_PROVIDER=groq        # anthropic | openai | groq | gemini
GROQ_API_KEY=
GROQ_MODEL=llama-3.3-70b-versatile
# OPENAI_API_KEY=
# ANTHROPIC_API_KEY=
# GEMINI_API_KEY=

# === TTS (опционально) ===
# Yandex SpeechKit для русского. Создаётся в Cloud Console
# (не AI Studio!) → Сервисный аккаунт → API-ключ → scope "yc.ai.speechkitTts.execute".
# Платёжный аккаунт обязателен (грант 4000₽ покрывает с лихвой).
YANDEX_SPEECHKIT_API_KEY=
# По умолчанию голос «alena», женский, 16kHz ogg/opus. Менять необязательно.
# YANDEX_SPEECHKIT_VOICE=alena

# Groq Orpheus для английского (после акцепта terms на console.groq.com).
# Использует тот же GROQ_API_KEY, отдельной переменной не нужно.

# === Google OAuth (опционально) ===
# https://console.cloud.google.com/apis/credentials
# Authorized redirect URI: http://localhost:3000/api/auth/callback/google
# GOOGLE_CLIENT_ID=
# GOOGLE_CLIENT_SECRET=

# === Azure Speech — пофонемная оценка произношения (опционально) ===
# Free F0 = 5 ч / месяц.
# AZURE_SPEECH_KEY=
# AZURE_SPEECH_REGION=westeurope
```

После любого изменения `.env.local` **перезапусти `npm run dev`** — Next подхватывает env только при старте.

## Опциональные интеграции (по очереди)

### 1. AI-помощник Lumos

Самое полезное расширение. Без него работают «механические» функции (журнал, словарь, чтение), но AI-чат, генератор уроков и Lumos-коррекция в парных диалогах будут писать «нет ключа провайдера».

- **Бесплатный путь — Groq**: https://console.groq.com → API Keys → Create. Это даст и LLM, и Orpheus-TTS на английском.
- **Альтернативы**: Anthropic / OpenAI / Gemini — раскомментируй соответствующие строки в `.env.local`.

### 2. Yandex SpeechKit (русский TTS)

Чтобы детское «прослушать слово» звучало голосом «Алёна», а не браузерным синтезом:

1. https://console.yandex.cloud → создай платёжный аккаунт (грант 4000 ₽).
2. **IAM** → **Сервисные аккаунты** → создай / открой существующий.
3. Кнопка «**Создать новый ключ → API-ключ**» (не «авторизованный ключ»!).
4. **Область действия**: `yc.ai.speechkitTts.execute`. Срок можно оставить пустой.
5. Скопируй значение → положи в `YANDEX_SPEECHKIT_API_KEY`.

Самая частая ошибка — не привязан платёжный аккаунт; без него API возвращает 403 даже с правильным ключом.

### 3. Groq Orpheus (английский TTS)

Активируется один раз вручную: https://console.groq.com/playground?model=canopylabs%2Forpheus-v1-english → введи любой английский текст → **Submit** → согласись с terms во всплывающем окне. После этого тот же `GROQ_API_KEY` начинает работать и для TTS.

### 4. Azure Pronunciation Assessment (произношение)

Нужно, только если хочешь пофонемный скоринг произношения учеников. Free F0 = 5 ч/мес. Без него `/student/pronunciation` использует упрощённый алгоритм на стороне браузера.

### 5. Google OAuth (вход через Google)

Без него останется обычный email + пароль (он работает «из коробки»). Для активации:

1. https://console.cloud.google.com/apis/credentials → **Create OAuth Client ID** → Web application.
2. Authorized redirect URIs: `http://localhost:3000/api/auth/callback/google`.
3. Положи `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` в `.env.local`.

## База данных

- Используется локальная **SQLite** через `better-sqlite3`. Файл создаётся автоматически при первом запросе: `data/spotlight.db` в корне репозитория.
- Миграция не нужна — все `CREATE TABLE IF NOT EXISTS` происходят в `src/lib/db.ts` при старте.
- **Сброс**: останови dev-сервер, удали папку `data/` и снова запусти `npm run dev` — получишь чистую базу.
- Для просмотра можно подключиться любым клиентом (DBeaver, TablePlus, `sqlite3 data/spotlight.db`).

## Скрипты пакета

```bash
npm run dev           # dev-сервер на http://localhost:3000 с горячей перезагрузкой
npm run build         # production-сборка
npm run start         # запуск production-сборки (после build)
npm run lint          # ESLint (Next eslint config)
npx tsc --noEmit      # проверка типов без сборки
```

Дополнительно в `scripts/`:

- `gen-content.mjs` — генерирует свежие уроки/тексты через LLM (нужен ключ).
- `promote.mjs` — переносит уже прочекенный контент из `scripts/out/` в `src/lib/*.ts`.
- `seed-methodical.mjs` — заливает методические скелеты в базу.

Запускать по необходимости: `node scripts/gen-content.mjs --grade 5 --module 2`.

## Чек-лист проверки

После `npm run dev` и открытия `localhost:3000` пройди по этому списку — займёт ~10 минут.

### A. Регистрация и навигация

- [ ] **Регистрация ученика** (`/auth/signup` → роль «Ученик», заполни ФИО, класс).
- [ ] Перенаправление на `/student` с виджетами «Сегодня», «Лента», «Кабинет учителя» скрыт.
- [ ] **Регистрация учителя** в инкогнито-окне → перенаправляет на `/teacher`.
- [ ] **Регистрация родителя** — на `/auth/signup` выбирай «Родитель», в профиле ученика возьми 6-знач код, введи в `/parent`.

### B. Контент (расширен в текущем PR)

- [ ] `/student/vocabulary` — 7 классов в селекторе. Для каждого ~80 слов (4 модуля × 20). Карточки + квиз работают.
- [ ] `/student/vocabulary` → вкладка **«Офлайн»** → «Скачать N слов» → выключи интернет в DevTools (Network → Offline) → «Учить» → флэш-карты идут.
- [ ] `/student/reading` — для каждого класса видны базовые тексты + «extras» (ids `rx-…`). Глоссарий и вопросы открываются.
- [ ] `/student/pair` — список сценариев: 4–5 на класс (магазин, кафе, зоопарк, интервью и т.д.).

### C. Учитель: журнал и доска

- [ ] `/teacher/journal` — клик по ФИО открывает дровер «Профиль ученика» с оценками/навыками/ошибками.
- [ ] **Горячие клавиши в ячейке журнала**: открой ячейку → `2`/`3`/`4`/`5`/`Н`/`.`/`Backspace`/`Esc`/`Enter`.
- [ ] **Доска** (`/teacher/board`) — теперь luxe-tldraw. Проверь:
  - открывается с пустым canvas, тулбар сверху,
  - рисование, прямоугольник, эллипс, текст, стикер, лазер, перетаскивание,
  - **«Сохранить»** → запись появляется в «Сохранённые доски» с миниатюрой,
  - клик по миниатюре загружает обратно,
  - **«PNG»** скачивает картинку,
  - **«Новая»** очищает,
  - **обнови страницу без сохранения** — черновик восстановится из IndexedDB (автосохранение).

### D. Социальные функции

- [ ] **Лента класса** (`/student/feed`) — открой в двух вкладках, поставь реакцию в одной → во второй счётчик прыгает мгновенно (SSE).
- [ ] **Чат класса** (`/student/classes/<id>/chat`) — сообщение по-английски от ученика → под бабблом всплывает Lumos-коррекция (если ключ AI задан).
- [ ] **Парный диалог** — создай комнату, скопируй 5-знач код, открой в инкогнито, войди → реплики идут по очереди, после реплики ученика — Lumos-tip.

### E. Голос и произношение

- [ ] `/student/vocabulary` → клик 🔊 рядом со словом — слышен Orpheus-голос (если ключ Groq настроен) или Алёна (если русский). Без ключей — Web Speech (хуже качества).
- [ ] `/student/reading` → крупная кнопка «Прослушать» — озвучка всего пассажа.
- [ ] `/student/pronunciation` — запись микрофоном, оценка точности (с Azure ключом — пофонемно, без — упрощённо).

### F. PWA

- [ ] DevTools → **Application** → **Manifest** валиден; **Service Workers** — `sw.js` зарегистрирован.
- [ ] Network → Offline → перезагрузи страницу → должна появиться красивая `/offline.html`, не дефолт.
- [ ] Установка: справа от адресной строки в Chrome — иконка «Установить приложение». Внизу сайдбара — «Установить приложение».

## Известные особенности и ограничения

- **Single-node**. SSE и pub/sub реализованы in-process (`feed-bus.ts`, `class-chat-bus.ts`). При горизонтальном масштабировании нужно подменить эти модули на Redis Pub/Sub (~100 строк кода).
- **SQLite, не Postgres**. Подходит для одной школы / одного учителя. Для многопользовательского prod нужен Postgres + миграции (Drizzle/Prisma).
- **Офлайн-словарь** — IndexedDB только в браузере, синк при появлении сети не реализован (нет конфликтов: записи независимы по `userId`).
- **Лимиты Lumos**: парный диалог — 30 реплик / комнату, чат класса — 500 символов / сообщение, классная лента — автоматически только из достижений (никакого свободного ввода у учеников, чтобы не было модерации).
- **Доска**: tldraw сохраняет полный snapshot (`document` + `session`) в JSON. Это много килобайт даже для пустой доски — нормально. Локальный черновик отдельно от сохранения по «Сохранить» — IndexedDB persistence по ключу `spotlight-teacher-board`.
- **TTS-фолбэк**: если оба ключа TTS (Yandex/Groq) недоступны или вернули 4xx/5xx, клиент автоматически переключается на `window.speechSynthesis`. Голоса хуже на macOS/iOS Safari.
- **Тёмная тема**: переключается из меню профиля. Все логотипы/иконки нарисованы вручную в SVG и работают в обоих режимах.

## Что делать, если что-то не работает

| Симптом | Причина / решение |
|---|---|
| `npm install` падает на `better-sqlite3` | Нужен Node 20+ и build-tools. На macOS: `xcode-select --install`. На Windows: `npm install --global windows-build-tools` (или WSL). |
| `npm run dev` стартует на `:3001` или другом порту | 3000 занят. Освободи или просто открой указанный порт. |
| 401 от `/api/…` после регистрации | Проверь, что `NEXTAUTH_SECRET` не пустой. Если изменил `.env.local` — перезапусти `npm run dev`. |
| `cookies must be a Promise` или подобное в логах | Чисти `.next/`: `rm -rf .next && npm run dev`. |
| Lumos «нет ключа провайдера» | В `.env.local` заполни `GROQ_API_KEY` (или другой) и перезапусти dev. |
| TTS возвращает 503 / Web Speech включается всё время | Проверь `YANDEX_SPEECHKIT_API_KEY` (для RU) и `GROQ_API_KEY` (для EN), а также что для Yandex есть платёжный аккаунт, а для Orpheus принят terms. |
| Доска долго грузится при первом открытии | tldraw — это ~1.5 МБ JS, кэшируется на следующие визиты. Нормально. |
| Service Worker не обновляется | DevTools → Application → Service Workers → **Unregister**, потом hard reload (`Cmd+Shift+R` / `Ctrl+Shift+R`). |
| После apt/brew-обновления `better-sqlite3` ругается на ABI | `npm rebuild better-sqlite3` либо `rm -rf node_modules && npm install`. |

Если ничего не помогло — пришли мне сюда лог из консоли (`npm run dev` + DevTools → Console), и я поправлю или дам обходной путь.

## Тех. карта проекта

```
src/
├ app/
│  ├ api/             # все endpoint'ы (chat, journal, board, feed, parent, pair, classes/.../chat)
│  ├ auth/            # signup / signin
│  ├ student/         # личный кабинет ученика
│  ├ teacher/         # личный кабинет учителя (включая /board на tldraw)
│  └ parent/          # read-only родительский кабинет
├ lib/
│  ├ curriculum.ts    # 28 модулей × 20 слов = расширенный план Spotlight 2-8
│  ├ vocabulary.ts    # ~560 переводов + примеров (используется flash-cards и квизом)
│  ├ readings.ts      # сгенерированный набор + readings-extra.ts (35 ручных текстов)
│  ├ scenarios.ts     # 30+ сценариев парного диалога
│  ├ feed-bus.ts      # in-process pub/sub для ленты
│  ├ class-chat-bus.ts# то же для чата класса
│  └ db.ts            # SQLite + миграции
├ types/index.ts      # все DTO
public/
├ sw.js               # service worker (cache-first статика, SWR API)
├ manifest.webmanifest
├ icon.svg / icon-maskable.svg / offline.html
RUNNING.md            # этот файл
README.md             # короткое описание для GitHub
```

Удачной проверки! Если есть вопросы по архитектуре или хочется что-то поменять — ставь задачу в той же ветке PR.
